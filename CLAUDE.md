# Maryama Web

Next.js 16 public website for Maryama, a guest house in Imsouane. Part of a monorepo alongside `../api` (backend) and `../backoffice`.

## Tech Stack

| Layer | Library |
|---|---|
| Framework | Next.js 16 (App Router, React 19), TypeScript 5 |
| UI | Chakra UI 3, Emotion |
| Server state | TanStack React Query 5 |
| API client | Auto-generated by Orval from the API's OpenAPI spec |
| i18n | next-intl, `src/localization/locales/fr.json` + `en.json` |
| Font | Montserrat via `next/font/google` |
| Lint | ESLint 9 (`eslint-config-next`, `no-console` is an error) |

## Commands

```bash
npm run dev                              # Dev server on http://localhost:3003
npm run build                            # Production build
npm run lint                             # ESLint
npm run generate:api                     # Regenerate API hooks/models (needs the API running, see below)
node src/localization/generateTKeys.js   # Regenerate tKeys.ts from fr.json
npx tsc --noEmit                         # Type-check
```

There is no test suite.

## Project Structure

```
src/
├── api/generated/
│   ├── endpoints/     # Orval-generated React Query hooks, split by tag — do not edit manually
│   └── models/        # Orval-generated DTOs — do not edit manually
├── app/[locale]/      # App Router pages; every route is locale-prefixed (fr default, en)
├── assets/
│   ├── colors/        # Semantic color tokens (COLORS.Text.Fg, COLORS.maryama.*)
│   └── fonts/         # Type scale (FONTS.T1.T{size}px.{weight}) + `montserrat`
├── components/
│   ├── core/          # App-wide pieces: Text, env banner, React Query provider
│   ├── landing/       # Landing-page sections; copy map in content.ts, visual constants in tokens.ts
│   └── ui/            # Chakra provider + Emotion cache
├── localization/      # next-intl routing/request config, locale JSON, generated tKeys.ts
├── proxy.ts           # next-intl middleware
├── types/             # Shared types (Locale, …)
└── utils/             # custom-instance.ts (Axios mutator used by Orval)
```

Each component lives in its own folder as `index.tsx` (+ `props.ts` when it has a props interface). Sub-components get a sub-folder (e.g. `faq/faq-item/`).

## Key Conventions

### Styling
- **Inline style props only.** Write Chakra props directly on the element (`<Box position="absolute" inset="0">`). No `styles.ts` files and no `const styles = {...}` section in a component.
- **Prefer `VStack` / `HStack`** over `Stack`, `Flex` or a wrapper `Box` for rows and columns. Both default to `align="center"` and `gap="0.5rem"`, so pass `align="stretch"` for columns of block content and an explicit `gap` (`gap="0"` if none).
- Don't put a `maxW` + `mx="auto"` container inside a stretched `VStack`: the auto margins shrink it to its content width. Keep those section wrappers as `Box`.

### Design system
- **Colors**: use `COLORS.*` or, on the landing page, `LANDING.*` from `components/landing/tokens.ts` (`cream`, `ink`, hairlines, `maxWidth`, `gutter`). Never hardcode hex values in JSX.
- **Fonts**: pass a `FONTS.T1.T14px.Regular`-style token to the core `<Text>` via its `font` prop. Wrap `<Text>` in a `Box` when you need letter-spacing, uppercase or opacity.
- **Text on dark grounds** (hero, room cards, footer): `color={COLORS.Text.FgInverse}`.
- **Responsive values**: Chakra object syntax, `{ base: '24px', md: '40px' }`. Spacing in the codebase is written in px.

### Icons
Icons are plain inline `<svg>` components in `components/landing/icons/` with `fill="none"` and `stroke="currentColor"`, so they inherit color from their parent.

### API layer
- Hooks live in `src/api/generated/endpoints/<tag>/` (e.g. `useRoomControllerFindAll`). Regenerate with `npm run generate:api`, never edit by hand.
- Orval reads the spec from `ORVAL_API_URL`, defaulting to `http://localhost:3000/docs-json`, so start `../api` first.
- The mutator `src/utils/custom-instance.ts` uses `NEXT_PUBLIC_API_URL` as the base URL and adds `Authorization: Bearer <token>` from `localStorage.token`.
- Components that call these hooks must be client components (`'use client'`).

### Translations
1. Add the string to **both** `fr.json` and `en.json`. `fr.json` is the source for key generation.
2. Run `node src/localization/generateTKeys.js` to regenerate `tKeys.ts`. Never edit `tKeys.ts` by hand.
3. Always go through `tKeys`, never raw strings: `t(tKeys.landing.hero.title)`.

Landing copy is centralised in `components/landing/content.ts`, which maps each section to its `tKeys` (plus image paths and anchors). Components read from it: `t(HERO.title)`.

When you remove a string, delete it from both JSON files, from `content.ts`, and regenerate `tKeys.ts`.

### Environment variables

| Variable | Purpose |
|---|---|
| `NEXT_PUBLIC_API_URL` | Base URL for the Axios mutator |
| `NEXT_PUBLIC_APP_ENV` | Env banner: `production` (green), `development` (red), anything else (purple). Falls back to `NODE_ENV` |
| `ORVAL_API_URL` | OpenAPI spec URL for `generate:api` (optional) |

Local values live in `.env.local`.

## Components Worth Knowing

- **`Text`** (`core/text`): Chakra `Text` with a `font` token prop, default `COLORS.Text.Fg` color, and an optional `hoverColor`.
- **`ImageSlot`** (`landing/image-slot`): cover-fit image box. Pass `ratio` for a fixed aspect ratio, otherwise it fills its parent. It shows a dashed labelled placeholder when `src` is missing, so sections can render before photos exist. Extra Box props are forwarded.
- **`SectionContainer`** (`landing/section-container`): the centred page-width column (`LANDING.maxWidth` + responsive gutter). Wrap every landing section in it and pass `as`, `id` and vertical padding as props.
- **`SplitSection`** (`landing/split-section`): `SectionContainer` + eyebrow `label` over a `1fr 1.35fr` grid, with the heading in `aside` and the body as `children`. Used by `ThePlace` and `Faq`.
- **`SectionLabel`** (`landing/section-label`): tracked uppercase eyebrow ("01 — The Place"). Accepts Box props for spacing.
- **`RoomCard`**: full-height room panel built from the raw API `Room`. Photo zooms on hover via `className="group"` + `_groupHover`.
- **`Navbar`**: fixed header that switches from transparent to solid cream once the `#top` hero scrolls out of view.
- **`FooterLink`** / **`SocialIconLink`** (`landing/site-footer/`): cream text link and 44px outlined icon button for the dark footer.
- **`EnvBanner`**: corner ribbon showing the current environment, rendered in the root layout.
